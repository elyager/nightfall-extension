## Short description

Comfortable dark mode, one site at a time. Adjust image brightness and keep your favorite sites easy to read.

## Detailed description

Nightfall turns bright pages into readable dark surfaces while keeping the colors that make a site feel like itself.

Choose the appearance for each site:

• Original: keep the website’s own appearance.
• Dark: apply Nightfall’s adaptive dark palette.
• AI: optionally generate a palette using your own OpenRouter API key.

Make the page comfortable for you:

• Allow access only to the sites where you want Nightfall, including matching subdomains.
• Remember your appearance choices for future visits.
• Dim images from 100% to 40% brightness without changing their colors.
• Use the element picker to darken individual elements the theme missed, with fixes saved for that page.
• Toggle Nightfall on the current allowed site with Ctrl+Shift+D, or Command+Shift+D on Mac. You can change the shortcut in Chrome’s extension shortcut settings.

Ordinary dark mode runs on your device. Nightfall has no advertising or analytics. Settings, generated palettes, and saved element fixes use local extension storage.

AI is optional. Only when you choose to generate, Nightfall sends a limited summary of page styles to OpenRouter and a model provider. This summary excludes page text, page URLs, selectors, IDs, classes, form values, cookies, and browser storage. Your API key is stored locally and sent to OpenRouter to authenticate requests. A zero-data-retention routing requirement is enabled by default; service and account policies still apply. AI availability depends on OpenRouter.

Chrome’s internal pages, the Chrome Web Store, and other protected browser pages cannot be modified. Website designs vary; if something needs attention, use the element picker or return to Original.

## Single purpose

Let users change the appearance of websites to a readable dark theme, with per-site preferences, image brightness, element fixes, and optional AI-generated color palettes supporting that same purpose.

## Reviewer instructions

1. Open a normal HTTP or HTTPS website and click Nightfall.
2. Choose Allow this site and approve Chrome’s optional site permission. Select Dark.
3. Adjust image brightness, try the element picker, and switch to Original to restore the page.
4. Ordinary Dark mode requires no account, credentials, payment, or special setup.
5. The optional AI feature requires the reviewer’s own valid OpenRouter API key and permission to connect to OpenRouter. Choose AI, enter the key, and select Generate and apply. A service request may fail if no suitable free endpoint meets the selected data policy. No developer test credentials are embedded or supplied.
