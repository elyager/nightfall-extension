Privacy policy

Effective September 8, 2026 · Nightfall 1.0.0

Nightfall processes page styles on your device in Dark mode. If you choose to generate an AI theme, it sends a limited summary of those styles to OpenRouter.

Who makes Nightfall

Nightfall is a Chrome extension developed by Erik Elyager. This policy covers the extension, this product website, and messages you send for support. Contact: elyager@gmail.com.

What stays in your browser

Nightfall reads page structure and computed styles to change the appearance of sites you allow. Ordinary dark mode does not send this information to the developer or to an AI service.

Nightfall uses Chrome’s local extension storage for:

  • Preferences: appearance mode, image brightness, site hostnames and their settings, and generated color palettes.
  • Element fixes: the page path and CSS selector of each element you choose to repair. Selectors can contain element IDs or class names.
  • Your optional OpenRouter API key: saved locally for future generation requests. It is sent to OpenRouter to authenticate those requests.
  • AI diagnostic logs: up to 20 recent response and error entries, including timestamps, status codes, retention preference, attempt number, and response text. The logger does not deliberately include the API key or outgoing page-style summary. Responses can include provider-supplied metadata.

These settings are not sent to the developer or synchronized by Nightfall to a cloud account. Page processing also uses temporary data in memory while the page is open.

When you use optional AI generation

AI mode requires your own OpenRouter API key and permission to connect to OpenRouter. When you select Generate and apply or Generate again, Nightfall sends an HTTPS request directly to OpenRouter, which routes it to a model provider to create a color palette.

The request includes aggregated colors and frequencies, broad font categories and sizes, spacing, surface shapes, element counts, a viewport-size category, and page color-scheme information. The style summary excludes page text, the page URL, CSS selectors, element IDs and classes, form values, cookies, and browser storage. It does not include screenshots or image contents.

OpenRouter receives your API key for authentication and normal connection information, such as your IP address. OpenRouter and its model provider process the style summary under their own policies. The generated palette is then saved locally.

Require zero-data retention is selected by default when the popup opens. It requests routing to an endpoint with a zero-data-retention policy. If you turn it off, this request no longer requires that restriction; your OpenRouter account settings can still impose it. This control does not guarantee that all service metadata is deleted. Review OpenRouter’s privacy policy, data-collection documentation, and retention controls before using AI mode.

Why Nightfall asks for access

  • Current tab: identifies the page when you open the extension or use its shortcut.
  • Scripting: applies and removes the bundled appearance code on allowed sites.
  • Storage: remembers your choices and the local data described above.
  • Optional site access: lets Nightfall style sites you explicitly allow, including matching subdomains. Access to OpenRouter is requested separately when you generate an AI theme.

Nightfall does not request permission to read Chrome’s browsing-history database.

Your choices and deletion

You can use Dark without an OpenRouter account. Choose Original to restore a site’s appearance. You can remove site access in Chrome’s extension settings.

Use Forget key in the AI section to delete the locally saved API key, Clear in OpenRouter logs to remove saved logs, or Clear beside element fixes to remove fixes for the current page. Local preferences and generated palettes remain until replaced or the extension’s local data is removed. Uninstalling Nightfall removes its local extension data from that Chrome profile.

Deleting local data does not delete records held by OpenRouter or a model provider. Manage those through the relevant service.

This website and support

This website has no advertising, analytics scripts, tracking cookies, or external fonts. It is hosted on Netlify. Netlify processes normal website connection and request information to deliver and secure the site; see Netlify’s privacy policy.

If you email support, Erik Elyager receives your email address, your message, and anything you attach. This information is used to respond and resolve your request. You can request deletion of support correspondence at the same address, subject to any necessary record-retention obligations. Please do not send API keys or other secrets.

Data use and policy changes

Nightfall does not sell user data, use it for advertising, or use it to determine creditworthiness. The developer does not receive extension telemetry or browsing activity. OpenRouter and its model provider process style summaries to generate the palettes you request. Erik Elyager uses support messages to respond to your requests.

Erik Elyager will update this policy when Nightfall’s data practices change. The effective date appears above. For questions about this policy or information you provided directly, contact Erik Elyager at elyager@gmail.com.

About the Chrome Web Store data labels

Authentication information and Location are data categories used by the Chrome Web Store. They are not permissions that let Nightfall read passwords, PINs, GPS coordinates, or your physical location.

  • Authentication information: only the OpenRouter API key you choose to provide. Nightfall saves it in local extension storage and sends it to OpenRouter to authenticate an AI theme-generation request.
  • Location: only the IP address that OpenRouter can receive from a normal direct internet connection. Nightfall does not request browser geolocation, GPS, coordinates, or location tracking.

These disclosures apply only when you choose to generate an AI theme. Regular Dark mode runs on your device. The separate browser permission requested for AI is limited site access to OpenRouter so the request can be sent.
